# 检测机构地图选点功能 — 需求规格

## 问题
在"新增/编辑检测机构"页面中，点击"地图选点"按钮仅弹出 `message.info('地图选点功能开发中')` 占位提示，无法实际选择地图位置。

## 目标
实现检测机构的地图选点功能，参考"新增公棚"页面的 `LoftMapPicker` 组件实现，支持：
- 在地图上点击选点
- 地址搜索定位
- 逆地理编码获取地址
- 经纬度回显与保存

## 用户故事
- 作为管理员，在填写检测机构地址时，点击"地图选点"按钮可打开地图弹窗，通过点击地图或搜索地址来精确定位机构位置，选点后地址和经纬度自动回填到表单中。

## 功能需求

### FR1: 地图选点弹窗
- 点击"地图选点"按钮打开 Modal，内嵌 `LoftMapPicker` 组件
- Modal 显示当前已保存的经纬度位置（编辑模式）

### FR2: 地图交互
- 支持在地图上点击选点
- 支持地址搜索定位（输入地址/地标名，定位到对应位置）
- 支持逆地理编码（选点后自动获取地址文本）
- 支持显示当前选点的经纬度

### FR3: 数据回填
- 选点确认后，地址回填到"机构地址"输入框
- 经纬度存储在表单状态中
- 已选点时显示经纬度预览（绿色提示框）

### FR4: 数据持久化
- 保存时将 location（JSON 字符串，含 lng/lat/address）提交到后端
- 后端在 `detection_orgs` 表中存储 location 字段
- 编辑模式回显已保存的位置数据

## 非功能需求
- 复用已有 `LoftMapPicker` 组件，保持一致性
- 支持高德/百度/腾讯三种地图服务商
- 地图未配置时显示友好提示（复用 LoftMapPicker 的已有逻辑）

## 约束与依赖
- 数据库 `detection_orgs` 表需新增 `location TEXT` 列
- 后端 API 需支持 location 字段的 CRUD
- 地图配置依赖系统配置中的地图服务商及 API Key

## 验收标准

| # | 标准 | 类型 |
|---|------|------|
| AC1 | 点击"地图选点"按钮能正常打开地图弹窗，显示地图组件 | rule |
| AC2 | 地图上点击任意位置能放置标记并显示经纬度 | rule |
| AC3 | 搜索地址能定位到对应位置并放置标记 | rule |
| AC4 | 选点后地址自动回填到表单地址输入框 | rule |
| AC5 | 选点确认后经纬度显示在绿色预览框中 | rule |
| AC6 | 保存机构时 location 数据正确提交到后端 | rule |
| AC7 | 编辑已有机构时能回显已保存的位置数据 | rule |
| AC8 | 地图未配置时显示友好提示，不报错 | rule |
| AC9 | 保存后数据库中 location 字段正确存储 | rule |
