# 修复身份证照片显示问题 - 产品需求文档

## 概述
- **摘要**: 修复认证审核页面中身份证正面照片无法正常显示的问题
- **目的**: 解决用户反馈的身份证照片显示失败问题，确保用户提交的认证材料能够正确预览
- **目标用户**: 后台管理员

## 问题分析
当前后端生成的身份证正面SVG代码存在XML结构问题：
1. `<defs>`标签被放在了使用它的`<rect>`标签之后
2. SVG元素 `<rect x='220'...fill='url(#photo)'/>` 引用的渐变在`<defs>`中定义，但`<defs>`出现在后面
3. 某些浏览器无法正确解析这种顺序错误的SVG，导致图片显示失败

## 修复方案
1. 重构`generateIdCardFrontSvg`函数，将`<defs>`标签移到SVG内容最前面
2. 检查其他SVG生成函数是否存在类似问题
3. 重新生成数据库中的认证材料数据

## 功能需求
- **FR-1**: 身份证正面SVG能正确显示
- **FR-2**: 身份证反面SVG能正确显示
- **FR-3**: 手持身份证SVG能正确显示
- **FR-4**: 所有认证材料在列表页和展开详情页都能正常预览

## 验收标准
### AC-1: 身份证正面照片显示
- **Given**: 用户有身份证正面照片数据
- **When**: 管理员访问认证审核页面
- **Then**: 身份证正面照片能正常显示缩略图
- **验证**: `programmatic`

### AC-2: 点击预览大图
- **Given**: 身份证正面照片缩略图正常显示
- **When**: 管理员点击缩略图
- **Then**: 能打开大图预览
- **验证**: `programmatic`

### AC-3: 其他认证材料显示
- **Given**: 用户有身份证反面和手持身份证照片数据
- **When**: 管理员访问认证审核页面
- **Then**: 所有认证材料都能正常显示
- **验证**: `programmatic`

## 技术约束
- 保持现有的SVG生成方式，仅修复XML结构顺序
- 保持现有的data URL编码方式
- 确保修改后数据库中的数据能正确渲染
