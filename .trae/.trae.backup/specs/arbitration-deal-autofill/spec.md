# 仲裁案件关联成交单自动回填与用户选择 - 产品需求文档

## 概述
- **摘要**: 为仲裁案件登记页面增加"关联成交单自动回填"功能，当管理员选择关联的拍卖成交单/交易订单后，系统自动获取该订单的双方当事人信息（申诉人=卖方、被诉人=买方）和成交价作为争议金额默认值，同时支持管理员手动修改或从用户库中搜索选择其他用户。
- **目的**: 减少仲裁案件登记时的重复录入工作，提高数据准确性和操作效率。管理员无需手动输入已知的当事人信息和金额，系统可自动从关联订单中提取。
- **目标用户**: 仲裁案件管理员、后台运营人员

## 目标
- 当选择关联成交单后，自动回填申诉人、被诉人和争议金额
- 申诉人和被诉人字段支持从系统用户库中搜索选择
- 自动回填的值可被管理员手动覆盖修改
- 未选择关联成交单时，保持原有手动输入模式不变

## 非目标（范围外）
- 不修改后端 API 接口
- 不修改仲裁案件数据模型
- 不涉及证据材料上传功能的改动
- 不涉及案件详情页的改动

## 背景与上下文
- 当前系统已有 `DealOption` 接口，包含 `buyer`、`seller`、`final_price` 字段
- 用户服务 `user.ts` 已有 `getUserList` 接口可按关键字搜索用户
- 仲裁案件表单在 `Case.tsx` 中，使用 Ant Design 的 Form 组件
- 当前关联成交单选择后不会自动填充任何字段，管理员需手动输入所有信息

## 功能需求

- **FR-1**: 当用户选择关联成交单后，系统自动将成交单的 `seller` 填入申诉人字段
- **FR-2**: 当用户选择关联成交单后，系统自动将成交单的 `buyer` 填入被诉人字段（若 buyer 为空则不填充）
- **FR-3**: 当用户选择关联成交单后，系统自动将成交单的 `final_price` 填入争议金额字段
- **FR-4**: 申诉人字段支持从系统用户库中搜索选择（使用 Select + showSearch），选中后自动填入用户昵称/姓名
- **FR-5**: 被诉人字段支持从系统用户库中搜索选择（使用 Select + showSearch），选中后自动填入用户昵称/姓名
- **FR-6**: 自动回填的字段值可被管理员手动覆盖修改，不锁定
- **FR-7**: 清除关联成交单后，已自动回填的字段保留不变（用户可手动清空或重新选择）
- **FR-8**: 当变更关联成交单时，若管理员未手动修改过对应字段，则自动更新回填值；若已手动修改则不覆盖

## 非功能需求

- **NFR-1**: 用户搜索响应时间应小于 500ms
- **NFR-2**: 自动回填操作应有明显的视觉反馈（如字段高亮或提示）
- **NFR-3**: 保持现有表单的数据提交逻辑不变

## 约束
- **技术**: React + TypeScript + Ant Design，需兼容现有 `getUserList` 和 `getDealOptions` 接口
- **业务**: 申诉人默认取成交单 seller，被诉人默认取成交单 buyer
- **依赖**: 后端 `/user/users` 接口需支持关键字搜索

## 假设
- 成交单的 `buyer` 字段可能为 null（拍卖未成交时），此时不自动填充被诉人
- 用户搜索返回的列表中 `nickname` 字段优先显示，若无则显示 `username`
- 管理员可能需要在不关联成交单的情况下手动输入当事人信息，此场景保持原有行为

## 验收标准

### AC-1: 关联成交单自动回填
- **给定**: 管理员正在登记新的仲裁案件，且系统中存在已完成的拍卖成交单
- **当**: 管理员在"关联成交单"下拉框中选择一个成交单
- **则**: 申诉人字段自动填入该成交单的 seller 名称；被诉人字段自动填入 buyer 名称（如有）；争议金额字段自动填入 final_price
- **验证**: `programmatic`
- **备注**: 三个字段应在选择后立即更新

### AC-2: 自动回填可手动覆盖
- **给定**: 管理员已选择关联成交单，系统已自动回填三个字段
- **当**: 管理员手动修改申诉人、被诉人或争议金额的当前值
- **则**: 字段值更新为管理员输入的值，且不再随成交单变更而自动覆盖（除非管理员重新选择成交单）
- **验证**: `human-judgment`

### AC-3: 申诉人/被诉人支持用户搜索选择
- **给定**: 管理员正在填写仲裁案件
- **当**: 管理员在申诉人或被诉人字段中输入关键字
- **则**: 显示系统中匹配的用户列表（显示昵称/用户名），管理员可选择其中一个用户
- **验证**: `programmatic`

### AC-4: 争议金额自动获取
- **给定**: 管理员选择了关联成交单
- **当**: 查看争议金额字段
- **则**: 字段值自动显示为该成交单的 final_price，且带有 ¥ 前缀格式化
- **验证**: `programmatic`

### AC-5: 未选择成交单时保持原有行为
- **给定**: 管理员未选择关联成交单
- **当**: 管理员手动填写申诉人、被诉人和争议金额
- **则**: 表单正常工作，不影响原有手动输入流程
- **验证**: `programmatic`

## 待解决问题

- [ ] 用户搜索是否需要输入最少字符限制？（建议最少 1 字符触发搜索）
