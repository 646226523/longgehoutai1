# 修复身份证照片缩略图显示问题 - 产品需求文档

## 概述
- **摘要**: 修复认证审核页面中身份证正面照片缩略图无法正常显示的问题
- **目的**: 解决用户反馈的认证材料缩略图显示异常问题，确保所有认证材料都能正确预览
- **目标用户**: 后台管理员

## 问题分析
当前列表页的认证材料缩略图显示存在问题：
1. Ant Design的Image组件处理data URL格式的SVG图片时可能存在兼容性问题
2. Image组件的width/height设置过小（52x36px），加上objectFit: cover会导致SVG内容被严重裁剪
3. SVG包含中文字符，使用encodeURIComponent编码后可能导致某些浏览器解析问题

## 修复方案
1. 后端优化SVG生成代码，使用更兼容的编码方式
2. 前端列表页使用原生img标签替代Ant Design的Image组件来显示缩略图
3. 保留Image.PreviewGroup用于点击预览大图功能
4. 调整缩略图尺寸和样式

## 功能需求
- **FR-1**: 认证材料列的身份证正面缩略图能正常显示
- **FR-2**: 认证材料列的身份证反面缩略图能正常显示
- **FR-3**: 认证材料列的手持身份证缩略图能正常显示
- **FR-4**: 点击缩略图能打开大图预览

## 验收标准
### AC-1: 身份证正面缩略图显示
- **Given**: 用户有身份证正面照片数据
- **When**: 管理员访问认证审核页面
- **Then**: 身份证正面缩略图能正常显示
- **验证**: `programmatic`

### AC-2: 点击预览大图
- **Given**: 身份证正面缩略图正常显示
- **When**: 管理员点击缩略图
- **Then**: 能打开大图预览
- **验证**: `programmatic`

### AC-3: 所有认证材料显示
- **Given**: 用户有所有认证材料数据
- **When**: 管理员访问认证审核页面
- **Then**: 三种认证材料缩略图都能正常显示
- **验证**: `programmatic`

## 技术约束
- 使用原生img组件替代Ant Design Image组件显示缩略图
- 保留Image.PreviewGroup用于大图预览功能
- 保持现有的SVG生成和编码方式
- 确保修改后浏览器兼容性良好
