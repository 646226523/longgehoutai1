# 赛事实时板块视觉与交互升级 - Product Requirement Document

## Overview
- **Summary**: 将中控数据中台右侧的“赛事实时”板块从枯燥的表格样式升级为现代化的卡片列表样式，通过可视化进度条、状态指示器和关键数据的重构排版，提升赛事信息的可读性和专业感。
- **Purpose**: 解决当前赛事表格样式“低级”、数据拥挤且难以一目了然的问题，将核心赛事信息通过更丰富的视觉元素（如进度条、时间地点、高亮数字）呈现给后台管理员。
- **Target Users**: 平台管理员、赛事运营人员

## Goals
- [P1] 将“赛事实时”从表格 (Table) 重构为“卡片列表” (Card List) 布局。
- [P2] 每个赛事卡片需包含：赛事名称、状态 Tag、进度条（可视化归巢进度）、核心数据（总羽数、已归巢、分速等）、以及关键信息（时间/地点）。
- [P3] 视觉风格与“热门拍卖”卡片保持一致，采用相同的渐变背景、圆角和边框风格。

## Non-Goals
- 不涉及后端接口变更。
- 不改变赛事数据的逻辑和 Mock 数据结构。
- 不新增额外的功能操作（如开赛、终止等），仅优化展示。

## Functional Requirements
- **FR-1**: 赛事列表以卡片形式展示，每项赛事一张卡片。
- **FR-2**: 卡片头部显示赛事名称和赛事状态（如进行中、即将结束等）。
- **FR-3**: 卡片中部显示进度条，直观展示赛事归巢进度，并显示百分比。
- **FR-4**: 卡片底部或侧边显示关键统计数据：总参赛羽数、已归巢羽数。
- **FR-5**: 卡片底部显示赛事的地点/线路信息（如“北京→上海”），提示赛事空间位置。
- **FR-6**: 保留操作按钮（详情、飞线），但样式需更精致紧凑。

## Non-Functional Requirements
- **NFR-1**: 卡片在 320px 宽度的容器内需完整显示，不允许横向滚动。
- **NFR-2**: 卡片采用 Flex 布局，响应式自适应。
- **NFR-3**: 采用暗色主题配色，保持与整体中控科技风格一致。

## Constraints
- **Technical**: 必须使用 React + TypeScript，复用现有的 Mock 数据结构 `RaceItem`。
- **Dependencies**: 依赖 Ant Design v5 组件库。

## Acceptance Criteria
### AC-1: 布局重构
- **Given**: 用户切换到“赛事实时”Tab
- **When**: 查看赛事列表
- **Then**: 赛事信息以卡片列表形式展示，而非表格形式。
- **Verification**: `programmatic` (DOM 结构无 `<table>` 标签)

### AC-2: 视觉优化
- **Given**: 用户查看单个赛事卡片
- **When**: 观察卡片样式
- **Then**: 卡片包含标题、状态、进度条、核心数据和操作按钮，信息层次分明，具有科技感。
- **Verification**: `human-judgment`

### AC-3: 响应式
- **Given**: 页面宽度为 1920x1080
- **When**: 查看右侧面板
- **Then**: 所有赛事卡片完整显示，无横向滚动条。
- **Verification**: `programmatic`
