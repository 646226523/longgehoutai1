# 资讯管理页面重构 - 实施计划

## [ ] 任务 1: 新增后端资讯统计接口
- **优先级**: 高
- **依赖**: 无
- **描述**:
  - 在 `admin-api/src/routes/content.ts` 中新增 GET /api/content/news/stats 接口
  - 返回统计数据：total（总数）、published（已发布数）、draft（草稿数）、offline（已下架数）、top（置顶数）
  - 统计数据通过 SQL 聚合查询实现
  - 在 `admin-web/src/services/content.ts` 中新增 NewsStats 接口类型和 getNewsStats 函数
- **验收标准**: AC-9
- **测试要求**:
  - `programmatic` TR-1.1: GET /api/content/news/stats 返回 { total, published, draft, offline, top } 数据结构
  - `programmatic` TR-1.2: 前端 getNewsStats() 函数可正确调用并返回数据
  - `programmatic` TR-1.3: 接口需登录鉴权 + content:view 权限
- **备注**: 浏览量字段暂不包含，news 表无此字段

## [ ] 任务 2: 实现统计看板组件
- **优先级**: 高
- **依赖**: 任务 1
- **描述**:
  - 创建 NewsDashboard 组件，展示5个核心指标卡片
  - 使用 Ant Design Card + Statistic 组件
  - 指标：总资讯、已发布、草稿、置顶、总浏览量
  - 每个卡片显示数值和趋势指示（使用箭头图标）
  - 数据通过 getNewsStats 接口获取
- **验收标准**: AC-1
- **测试要求**:

  - `human-judgement` TR-2.2: 每个卡片显示正确的数值和趋势方向
  - `programmatic` TR-2.3: 数据加载失败时有降级处理
- **备注**: 可参考 Banner.tsx 中的 BannerDashboard 组件实现

## [ ] 任务 4: 重构列表表格 - 封面列、状态列优化
- **优先级**: 高
- **依赖**: 无

## [ ] 任务 5: 重构操作列 - 按钮分组与风险分级
- **优先级**: 高
- **依赖**: 无
- **描述**:
  - 操作按钮按三组展示：
    - 内容操作：[编辑] [预览]（蓝色 link 样式）
    - 状态操作：[发布/下架] [置顶/取消置顶]（根据状态动态显示）
    - 危险操作：[删除]（红色文字，Popconfirm 二次确认）
  - 根据当前资讯状态智能显示可用按钮：
    - 草稿：显示[编辑][预览][发布][置顶][删除]
    - 已发布：显示[编辑][预览][下架][取消置顶][删除]
    - 已下架：显示[编辑][预览][发布][置顶][删除]
  - 所有操作使用 Popconfirm 确认（删除必须确认）
- **验收标准**: AC-4
- **测试要求**:
  - `human-judgement` TR-5.1: 操作按钮按分组展示，视觉层次清晰
  - `programmatic` TR-5.2: 不同状态的资讯显示正确的操作按钮
  - `programmatic` TR-5.3: 点击删除弹出二次确认对话框
  - `human-judgement` TR-5.4: 危险操作按钮为红色警示色
- **备注**: 参考 Banner.tsx 的操作按钮实现
