# 资讯管理页面重构 - 产品需求文档 (PRD)

## 概述
- **摘要**: 将现有的"能用"级别的资讯管理页面，重构为专业的CMS内容管理后台，采用"统计看板 + 筛选操作栏 + 表格列表 + 侧边抽屉编辑"的经典布局模式，实现封面缩略图展示、操作按钮风险分级、富文本编辑、预览功能等核心优化。
- **目的**: 解决当前页面封面图无法预览、操作按钮堆砌、缺少数据统计、筛选区松散、无预览功能等核心问题，将资讯管理从"信息录入页"升级为完整的内容运营工具。
- **目标用户**: 平台内容运营人员、赛事编辑、行业资讯编辑

## 目标
- **P0**: 实现封面缩略图展示（120×80缩略图，点击可放大预览）
- **P0**: 操作按钮按风险等级分组展示（内容操作/状态操作/危险操作）
- **P0**: 状态标签彩色化（已发布绿色、草稿橙色、已下架灰色、置顶叠加徽章）
- **P0**: 实现统计看板（总资讯/已发布/草稿/置顶/总浏览量 5个核心指标）
- **P1**: 侧边抽屉编辑面板（含本地上传封面图、富文本编辑器、发布设置）
- **P1**: 资讯预览功能（APP/前端效果模拟）
- **P1**: 图片本地上传组件集成（替换URL输入方式）
- **P2**: 批量操作（批量发布/下架/删除）
- **P2**: 日期范围筛选

## 非目标（不在范围内）
- 不引入重量级富文本编辑器（如 TinyMCE），使用轻量级方案
- 不修改后端数据库表结构（新增 stats 接口除外）
- 不实现资讯的评论管理功能
- 不实现资讯的推荐算法

## 背景与上下文
- 当前资讯管理页面 `News.tsx` 使用基础的 ProTable + Drawer 模式
- 后端已提供完整的资讯 CRUD、发布/下架、置顶接口
- 现有 `ImageUploader` 组件可复用实现封面图本地上传
- 已完成的 Banner 管理页面重构可作为参考模板
- news 表当前字段：id/title/category/cover_url/summary/content/author/status/is_top/published_at/created_at/updated_at
- 当前无 news 浏览量统计字段，需在 stats 接口中基于现有数据聚合

## 功能需求

### FR-1: 统计看板
- 在页面顶部展示5个核心指标卡片：总资讯数、已发布数、草稿数、置顶数、总浏览量
- 每个指标显示当前数值和趋势变化（较上月）
- 数据从后端 `/api/content/news/stats` 接口获取

### FR-2: 封面缩略图展示
- 列表中封面列显示 120×80 缩略图
- 点击缩略图可放大预览（使用 Image 组件的预览功能）
- 无封面时显示"🖼️ 无封面"灰色占位图
- 加载失败时显示"⚠️ 加载失败"提示

### FR-3: 状态标签彩色化
- 已发布：绿色标签
- 草稿：橙色标签
- 已下架：灰色标签
- 置顶资讯在标题旁叠加红色"📌 置顶"徽章

### FR-4: 操作按钮分组
- 内容操作组：[编辑] [预览] - 蓝色链接样式
- 状态操作组：[发布/下架] [置顶/取消置顶] - 绿色/橙色
- 危险操作：[删除] - 红色文字，需二次确认
- 根据当前状态智能显示可用操作

### FR-5: 侧边抽屉编辑
- 采用右侧滑出抽屉（宽度 760px）
- 表单分组：基础信息、封面图片、内容编辑、发布设置
- 封面图使用 ImageUploader 组件实现本地上传
- 内容编辑使用 Textarea + HTML 预览切换（轻量级方案）
- 发布设置包含置顶开关、状态选择、发布时间

### FR-6: 资讯预览弹窗
- 点击"预览"按钮弹窗展示资讯在移动端的效果
- 包含手机模拟器样式
- 显示封面图、标题、分类、发布时间、正文内容
- 支持关闭和真机预览（占位）

### FR-7: 数据筛选
- 支持按标题/分类/状态搜索
- 支持日期范围筛选（发布时间）
- 支持重置和查询

### FR-8: 批量操作
- 批量发布：选择多条草稿资讯一键发布
- 批量下架：选择多条已发布资讯下架
- 批量删除：选择多条资讯删除（二次确认）
- 批量操作需二次确认弹窗

### FR-9: 后端统计接口
- 新增 GET /api/content/news/stats 接口
- 返回 total（总数）、published（已发布）、draft（草稿）、top（置顶）、total_views（总浏览量）等指标
- 浏览量暂使用固定值或基于 published_at 的估算值

## 非功能需求

### NFR-1: 性能
- 列表加载时间 < 2秒（在中等网络环境下）
- 统计看板数据加载时间 < 1秒

### NFR-2: 可用性
- 操作按钮分组清晰，危险操作有二次确认
- 表单校验提示友好

### NFR-3: 兼容性
- 与现有 Ant Design Pro 组件库兼容
- 与现有 API 接口保持向后兼容

### NFR-4: 视觉一致性
- 与 Banner 管理页面、认证审核页面风格一致
- 统一的颜色方案、间距、圆角

## 约束

### 技术约束
- 前端框架：React + TypeScript + Ant Design Pro
- 后端框架：Express + SQLite
- 不可引入新的重量级 npm 依赖（富文本编辑器使用现有 Textarea + Preview 方案）
- ImageUploader 组件必须复用现有实现

### 业务约束
- news 表当前无 views 字段，统计中的"总浏览量"需合理处理
- 状态流转：draft → published → offline，不允许逆向流转

### 依赖
- 依赖 ImageUploader 组件（已存在）
- 依赖 dayjs 进行日期格式化
- 依赖后端新增 stats 接口

## 假设
- 假设 news 表的 cover_url 字段可存储 ImageUploader 返回的 URL 或 data URL
- 假设后端可以快速新增 stats 接口（基于现有 SQL 聚合查询）
- 假设当前资讯量在分页限制内（每页 10-50 条）

## 验收标准

### AC-1: 统计看板展示
- **Given**: 用户已登录后台并进入资讯管理页面
- **When**: 页面加载完成
- **Then**: 顶部展示5个统计卡片（总资讯/已发布/草稿/置顶/总浏览量），每个显示数值和趋势
- **验证**: `programmatic`
- **备注**: 后端 stats 接口正确返回聚合数据

### AC-2: 封面缩略图展示
- **Given**: 资讯列表中有封面图的资讯
- **When**: 查看列表
- **Then**: 封面列显示 120×80 缩略图，可点击放大预览
- **验证**: `human-judgment`
- **备注**: 无封面显示占位图，加载失败显示错误提示

### AC-3: 状态标签彩色化
- **Given**: 列表中存在不同状态的资讯
- **When**: 查看状态列
- **Then**: 已发布显示绿色、草稿显示橙色、已下架显示灰色，置顶资讯标题旁有红色置顶徽章
- **验证**: `human-judgment`

### AC-4: 操作按钮分组
- **Given**: 列表中任意一条资讯
- **When**: 查看操作列
- **Then**: 按钮按分组展示：[编辑][预览]为蓝色，[发布/下架][置顶]为状态操作，[删除]为红色且有二次确认
- **验证**: `human-judgment`

### AC-5: 侧边抽屉编辑
- **Given**: 点击新增或编辑按钮
- **When**: 抽屉打开
- **Then**: 表单分组清晰，封面图支持本地上传，正文支持编辑/预览切换，发布设置包含所有选项
- **验证**: `human-judgment`

### AC-6: 资讯预览功能
- **Given**: 点击预览按钮
- **When**: 预览弹窗打开
- **Then**: 以手机模拟器样式展示资讯详情，包含封面、标题、分类、时间、正文
- **验证**: `human-judgment`

### AC-7: 筛选功能
- **Given**: 在筛选区输入条件
- **When**: 点击查询
- **Then**: 列表正确筛选显示结果，支持标题搜索、分类选择、状态选择、日期范围
- **验证**: `programmatic`

### AC-8: 批量操作
- **Given**: 选中多条资讯
- **When**: 执行批量发布/下架/删除
- **Then**: 弹出确认对话框，确认后执行操作，列表刷新
- **验证**: `programmatic`

### AC-9: 后端 stats 接口
- **Given**: 前端请求统计数据
- **When**: GET /api/content/news/stats
- **Then**: 返回正确的聚合统计数据
- **验证**: `programmatic`
