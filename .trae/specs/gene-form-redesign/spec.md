# 新增基因档案页面重构 - 产品需求文档

## Overview
- **Summary**: 将现有"新增基因档案"抽屉表单从扁平单列表单升级为分组卡片式双栏布局表单,实现图片本地上传、字段分组、关联数据搜索选择、实时校验与预览等核心功能,将"录入页面"升级为"信息管理工具"
- **Purpose**: 解决当前页面操作效率低、数据一致性差、缺乏实时反馈等痛点,提升后台管理员的数据录入体验与准确率
- **Target Users**: 赛鸽基因溯源平台的后台管理员、基因档案录入人员

## Goals
- 实现图片本地上传(拖拽+点击+粘贴),替代 URL 输入方式
- 将 20+ 字段按业务逻辑分为 6 个分组,采用 2 列并排布局
- 关键关联字段(鸽主、父鸽、母鸽)从文本输入升级为搜索选择器
- 足环号实时校验(格式+唯一性),提交前即可发现错误
- 右侧实时预览面板,提交前确认信息无误
- 响应式适配:宽屏左右分栏,窄屏上下结构

## Non-Goals (Out of Scope)
- 不涉及后端 API 变更(前端仍使用现有接口,仅新增 Mock 数据支持)
- 不实现图片裁剪功能(后续 P2 阶段)
- 不实现鸽主快速新增弹窗(后续 P2 阶段)
- 不涉及基因档案详情页的重构
- 不修改列表页的表格展示逻辑

## Background & Context
- 当前实现使用 `DrawerForm`(560px 宽),所有字段平铺单列,体验较差
- 项目使用 React 18 + Ant Design 5 + Pro Components + TypeScript + Vite
- 已有 Mock 服务层,前端开发无需真实后端
- `services/gene.ts` 已封装所有基因档案相关 API
- `server/mock.ts` 包含 Mock 数据,需扩展基因档案相关 Mock 接口

## Functional Requirements

### FR-1: 图片本地上传
- 支持点击选择文件 + 拖拽上传 + Ctrl+V 粘贴
- 支持 JPG/PNG/WEBP 格式,单文件 ≤ 5MB
- 上传后右侧预览区实时显示图片
- 无图片时显示鸽子剪影占位图
- 上传失败时显示错误提示

### FR-2: 字段分组与布局
- 6 个分组:基础信息(必填)、外观特征、鸽主信息、遗传数据、亲子关系、档案状态
- 宽屏(≥1920px):左右分栏(表单 60% + 预览 40%),2 列并排
- 窄屏(<1920px):上下结构,1 列布局
- 每组之间有视觉分隔(分割线或卡片边框)

### FR-3:足环号实时校验
- 格式校验:实时校验是否符合 CN-YYYY-XX-XXXXXX 格式
- 唯一性校验:输入后防抖 1 秒请求后端/Mock 校验是否已存在
- 错误反馈:输入框下方红色提示"足环号格式错误"或"该足环号已存在"
- 新增态可编辑,编辑态禁用

### FR-4:关联字段搜索选择器
- 鸽主:搜索选择已有鸽主,选择后自动回填鸽主电话
- 父鸽/母鸽:搜索已有基因档案(按足环号/鸽名),显示简略信息
- 支持清空选择

### FR-5:下拉选择替代文本输入
- 羽色:下拉选择(灰/雨点/白/红轮/花/石板/其他)
- 眼砂:下拉选择(黄眼/砂眼/牛眼)
- 性别:单选按钮组(雄/雌/未知)
- 档案状态:单选按钮组(正常/停用)

### FR-6:右侧实时预览面板
- 实时显示已填写字段摘要:足环号、鸽名、品系、鸽主、照片
- 未填写字段显示占位虚线
- 照片预览区与右侧同步
- 预览数据随表单输入实时更新

### FR-7:操作按钮优化
- 底部操作区:取消 | 确定 | 保存并新增下一个
- 保存并新增:提交成功后清空表单,保持抽屉打开
- 确定:提交成功后关闭抽屉

### FR-8:响应式适配
- ≥1920px:左右分栏布局,2 列并排
- <1920px:上下结构,1 列布局,预览面板折叠至底部

## Non-Functional Requirements

### NFR-1: 性能
- 足环号唯一性校验防抖 1 秒,避免频繁请求
- 图片上传前自动压缩(若原图 > 2MB)
- 表单渲染 < 500ms(首次打开)

### NFR-2: 体验
- 所有必填字段有明显标识(红色星号)
- 表单提交前校验所有必填项,不通过时自动滚动到第一个错误字段
- 操作反馈 < 0.3 秒(视觉响应)

### NFR-3: 兼容性
- 支持 Chrome、Edge 最新两个版本
- 最小宽度支持:1280px

## Constraints
- **Technical**: React 18 + Ant Design 5 + TypeScript,不可引入新 UI 库
- **Business**: MVP 优先,先实现 P0 功能,P1/P2 后续迭代
- **Dependencies**: 依赖 `services/gene.ts` API 层,需扩展 Mock 数据

## Assumptions
- 假设后端接口 `/gene/profiles` 支持 multipart 文件上传(或后续会支持)
- 假设鸽主数据可通过现有接口获取(或需新增 Mock 接口)
- 假设足环号格式为 CN-YYYY-XX-XXXXXX(可根据实际调整)
- 假设图片上传后返回可访问的 URL,存入 `photo_url` 字段

## Acceptance Criteria

### AC-1: 图片本地上传
- **Given**: 用户打开新增基因档案抽屉
- **When**: 用户点击上传区域或拖拽 JPG/PNG 文件到上传区
- **Then**: 右侧预览区实时显示上传的图片,文件大小和格式校验通过
- **Verification**: `programmatic`

### AC-2: 字段分组布局
- **Given**: 用户在 ≥1920px 分辨率下打开抽屉
- **When**: 抽屉渲染完成
- **Then**: 表单分为 6 个分组,2 列并排布局,右侧为预览面板
- **Verification**: `human-judgment`
- **Notes**: 检查分组逻辑是否清晰、布局是否合理

### AC-3:足环号实时校验
- **Given**: 用户在新增态输入足环号
- **When**: 输入格式不正确或已存在
- **Then**: 输入框下方显示红色错误提示,提交按钮不可用
- **Verification**: `programmatic`

### AC-4:关联字段搜索选择
- **Given**: 用户点击鸽主/父鸽/母鸽选择器
- **When**: 输入关键词搜索
- **Then**: 显示匹配的选项列表,选择后自动回填关联字段
- **Verification**: `programmatic`

### AC-5:下拉/单选替代文本输入
- **Given**: 用户打开新增/编辑抽屉
- **When**: 查看性别、羽色、眼砂、状态字段
- **Then**: 显示为下拉选择或单选按钮,而非文本输入框
- **Verification**: `programmatic`

### AC-6:实时预览面板
- **Given**: 用户在填写表单过程中
- **When**: 任意字段值发生变化
- **Then**: 右侧预览面板实时更新显示最新摘要信息
- **Verification**: `programmatic`

### AC-7:保存并新增
- **Given**: 用户填写完表单并点击"保存并新增下一个"
- **When**: 提交成功
- **Then**: 清空表单(保留默认值),抽屉保持打开,显示成功提示
- **Verification**: `programmatic`

### AC-8:响应式适配
- **Given**: 用户在不同分辨率下打开抽屉
- **When**: 分辨率变化
- **Then**: 布局自动切换(宽屏左右分栏,窄屏上下结构)
- **Verification**: `human-judgment`
