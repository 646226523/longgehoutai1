# 中控数据中台全面重构 - Product Requirement Document

## Overview
- **Summary**: 对现有中控数据中台进行全面重构，解决页面死板、右侧信息无法完整显示、左侧公棚信息占比过大、地图交互能力不足、底部飞行数据占比过大等5大问题，打造现代科技感的指挥调度中心。
- **Purpose**: 将"数据展示板"升级为"决策作战指挥舱"，让后台管理员能够一屏掌握全局、一眼识别关键、一键操作处理。
- **Target Users**: 平台管理员、公棚运营人员、赛事调度员

## Goals
- [P1] 页面整体布局更现代、更有层次感，支持灵活调整信息密度
- [P2] 右侧热门拍卖/赛事实时信息无需横向拖动即可完整显示，布局清晰有序
- [P3] 左侧公棚总数信息栏占比缩小至合理范围，重点指标一眼可见
- [P4] 中间地图支持省份下钻、公棚节点/飞行轨迹自由切换，点击省份后聚焦展示该省份数据
- [P5] 底部鸽子实时飞行数据采用紧凑行式布局，屏幕占比合理

## Non-Goals (Out of Scope)
- 不涉及后端接口改造，保持现有 mock 数据结构
- 不新增用户权限体系
- 不改动路由和导航结构
- 不实现真实的地图 API 对接（保持 ECharts 中国地图）

## Background & Context
- 当前文件：`src/pages/datacenter/index.tsx`（约794行）
- 技术栈：React + TypeScript + ECharts + Ant Design v5
- 设计风格：暗色科技风（深蓝黑背景 `#0a1128`，卡片 `#1a2332`，青色 `#00d4ff`，金色 `#ffcc00`）

## Functional Requirements

### FR-1: 整体布局重构
- 采用"顶部导航栏 + 三栏主体 + 底部折叠面板"的经典指挥舱布局
- 顶部：标题 + 实时时钟 + 状态指示器 + 刷新/全屏按钮 + 快捷筛选
- 三栏比例优化为 25% : 50% : 25%（固定右侧 320px 宽度）
- 整体支持自适应高度，在 1080p/1440p 分辨率下均表现良好

### FR-2: 左侧指标卡紧凑化
- 将现有 4 个 MetricCard 精简为 4 列紧凑布局（单行横排）
- 每个指标卡高度控制在 80px 以内
- 去除 Sparkline 微趋势图的大块区域，用 inline 迷你 sparkline 替代
- 省份 TOP10 图表高度压缩至 240px

### FR-3: 右侧拍卖/赛事信息优化
- 热门拍卖：采用卡片列表式布局，每张卡片紧凑显示拍卖名、当前价、出价数、倒计时
- 支持分页（每页 5 条），无需横向拖动
- 赛事实时：采用紧凑表格布局，显示赛事名/进度/状态/操作
- Tab 切换流畅，active 状态明确

### FR-4: 地图交互升级
- 支持"公棚节点"和"飞行轨迹"两种视图切换（Tag 切换已存在但体验不佳）
- 点击省份后：地图缩放到该省份，右侧面板切换为该省份的详细数据
- 省份数据展示：公棚数量、在线数、鸽子总数、进行中赛事
- 支持返回全国视图

### FR-5: 底部飞行数据优化
- 采用单行紧凑列表布局，每行高度控制在 36px 以内
- 默认折叠，点击展开查看全部
- 状态标签采用彩色点状标识，文字精简
- 支持异常置顶、状态筛选

### FR-6: 全局信息层级
- 重要指标使用大号字体 + 发光效果
- 次要指标使用中号字体 + 常规颜色
- 趋势/变化量使用上行青色 / 下行红色

## Non-Functional Requirements
- **NFR-1**: 页面首屏渲染时间 < 1.5s
- **NFR-2**: ECharts 图表切换动画流畅，无明显卡顿
- **NFR-3**: 在 1920×1080 分辨率下所有内容可见，无横向滚动条
- **NFR-4**: 暗色主题配色统一，色彩对比度符合可读性标准（WCAG AA）

## Constraints
- **Technical**: 必须使用 ECharts 渲染图表，Ant Design v5 组件，React Hooks 管理状态
- **Business**: 保持现有数据接口兼容，不修改 mock 数据结构
- **Dependencies**: 依赖 echarts 中国地图 JSON 远程加载

## Assumptions
- 管理员使用 1080p 及以上分辨率显示器
- 浏览器支持 ES2020+ 和 CSS Grid/Flexbox
- 网络可访问 jsdelivr CDN 加载 ECharts 地图数据

## Acceptance Criteria

### AC-1: 整体布局优化
- **Given**: 管理员访问中控数据中台页面
- **When**: 页面完全加载
- **Then**: 左侧 4 个指标卡在一行内紧凑显示，下方省份图表高度合理，右侧拍卖/赛事 Tab 内容无需横向拖动即可完整查看，底部飞行数据可折叠展开
- **Verification**: `human-judgment`

### AC-2: 右侧信息完整性
- **Given**: 管理员切换到"热门拍卖"Tab
- **When**: 查看拍卖列表
- **Then**: 每条拍卖信息在卡片内完整显示（名称、价格、出价数、倒计时、热度），无需横向滚动，支持分页切换
- **Verification**: `human-judgment`

### AC-3: 地图省份下钻
- **Given**: 管理员在"公棚节点"视图
- **When**: 点击地图上的某个省份/城市节点
- **Then**: 地图缩放到该区域，右侧面板显示该省份的详细统计数据，提供"返回全国"按钮
- **Verification**: `programmatic`

### AC-4: 底部飞行数据紧凑
- **Given**: 管理员查看底部飞行数据
- **When**: 展开飞行数据面板
- **Then**: 每行数据高度不超过 40px，显示足环号/位置/速度/状态/预计归巢时间，异常鸽子置顶并高亮
- **Verification**: `human-judgment`

### AC-5: 构建成功
- **Given**: 所有代码修改完成
- **When**: 运行 `npm run build`
- **Then**: 构建成功，无 TypeScript 错误
- **Verification**: `programmatic`
