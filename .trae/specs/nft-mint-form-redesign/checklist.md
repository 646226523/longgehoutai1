# 新增铸造申请页面重构 - 验证清单

## P0 核心功能
- [x] 「资产图片 URL」输入框已完全移除，替换为 ImageUploader 本地上传控件（虚线框+加号+文字提示）
- [x] 「元数据(JSON)」文本域已完全移除，抽屉内不再出现"元数据"或"JSON"字样输入控件
- [x] 「关联基因档案」下拉框改为 SearchSelect 搜索选择器，搜索项显示「足环号 + 鸽名 + 品系 + 鸽主」组合文案而非简单单行
- [x] 选择基因档案后，资产名称自动回填为鸽名，持有者自动回填为鸽主名
- [x] 提交草稿时 payload.metadata 为自动生成的合法对象（包含 name / ring_number / breed / gender / color / eye_color / owner + 自定义键值对），无需用户手写 JSON
- [x] 底部按钮区显示「取消 / 保存草稿 / 提交上链审核」三按钮；「提交上链审核」需二次确认，且会自动调用 submitNftAssetAudit

## P1 预览与体验
- [x] ≥1920 分辨率：抽屉打开后左侧表单、右侧 NFT 预览卡片分栏布局；<1920 时合理降级（上下结构或 7:3 分栏）
- [x] 右侧预览卡片实时联动：上传图片 / 修改资产名称 / 选择基因档案后，≤ 300ms 更新预览图、标题、品系、鸽主
- [x] 「生成描述」按钮点击后自动填入模板文案，描述框右下角显示"当前字数/200"，字数限制生效
- [x] 自定义属性键值对表格：三列（属性名 / 属性值 / 删除），支持【+ 添加属性】；初始默认显示眼砂、羽色、性别三行

## P2 扩展与兼容
- [x] 选择基因档案时，若基因档案有 photo_url 则自动带入资产图片（允许操作员点击替换）
