# 工作台重构 - PRD

## Overview
- **Summary**: 将当前静态数据展示型工作台升级为智能决策辅助平台，核心升级包括：核心指标三位一体展示、趋势分析图表、实时预警中心、智能快捷入口。
- **Purpose**: 解决当前工作台"数据孤岛、缺少趋势、缺乏预警、功能单一"四大问题，为管理员提供真正能辅助决策的数据洞察。
- **Target Users**: 后台管理员、运营人员

## Goals
- 核心指标卡片升级为"数值+趋势+健康度"三位一体
- 新增趋势分析区域（近7天核心指标折线图）
- 新增实时预警中心（四级预警）
- 快捷入口增加状态提示（待办数量）
- 所有数据使用 Mock 数据模拟（后端接口待对接）

## Non-Goals
- 不修改后端 API 接口
- 不引入第三方图表库（使用纯 SVG 实现）
- 不修改其他页面的组件

## Functional Requirements

### FR-1: 核心指标卡片升级
- 4 个指标卡片展示：基因档案总数、NFT 资产数、进行中赛事、注册用户数
- 每个卡片包含：主数值、趋势百分比（↑↓）、健康度标签、进度条、辅助信息
- 点击卡片跳转到对应详情页

### FR-2: 趋势分析模块
- 展示近 7 天核心指标变化趋势（折线图）
- 支持切换时间范围：近 7 天 / 近 30 天
- 鼠标悬停显示具体数值
- 数据洞察文字说明

### FR-3: 实时预警中心
- 四级预警：🔴 紧急、🟡 重要、🔵 提醒、🟢 正常
- 展示预警标题、时间、操作链接
- "查看全部"入口

### FR-4: 快捷入口升级
- 每个快捷入口卡片显示待办数量徽章
- 基因档案：待审核数量
- NFT 资产：待上架数量
- 赛事管理：进行中数量
- 用户管理：待审核数量

### FR-5: Mock 数据
- 所有数据使用本地 Mock
- 模拟数据符合赛鸽业务场景

## Non-Functional Requirements
- **NFR-1**: 首屏加载 < 1s（所有数据本地 Mock）
- **NFR-2**: 响应式布局适配（移动端可用）
- **NFR-3**: TypeScript 类型安全

## Acceptance Criteria

### AC-1: 指标卡片三位一体
- **Given**: 工作台加载完成
- **When**: 观察指标卡片
- **Then**: 每个卡片显示主数值 + 趋势百分比 + 健康度标签 + 进度条
- **Verification**: `human-judgment`

### AC-2: 趋势分析图表
- **Given**: 工作台加载完成
- **When**: 观察趋势分析区域
- **Then**: 显示近 7 天折线图，包含 3 条数据线（基因、用户、NFT）
- **Verification**: `human-judgment`

### AC-3: 预警中心
- **Given**: 工作台加载完成
- **When**: 观察预警中心
- **Then**: 至少显示 2 条预警，颜色分级正确
- **Verification**: `human-judgment`

### AC-4: 快捷入口状态
- **Given**: 工作台加载完成
- **When**: 观察快捷入口
- **Then**: 每个卡片显示对应状态数量
- **Verification**: `human-judgment`

### AC-5: TypeScript 编译通过
- **Given**: 修改完成
- **When**: 运行 `npx tsc --noEmit`
- **Then**: 零错误
- **Verification**: `programmatic`
