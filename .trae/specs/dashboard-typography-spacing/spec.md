# 工作台三板块字体与间距优化 - 产品需求文档

## 概述
- **摘要**: 针对工作台预警中心、注册端口分析、登录端口分析三个板块的字体过小、间距不合理问题进行优化，提升可读性和视觉舒适度。
- **目的**: 解决用户反馈的"字体过小、信息拥挤、悬浮提示不清晰"等体验问题。
- **目标用户**: 后台管理员

## 目标
- 将三个板块的核心展示内容字体统一调整为14px
- 修复端口分析左侧标题与数据参数间距过宽问题，调整为5px
- 优化饼状图百分比标签字号
- 将饼状图悬浮提示字体调整为16px并加粗，实现自定义HTML Tooltip

## 非目标
- 不改变板块整体布局结构
- 不修改配色方案
- 不调整卡片尺寸

## 背景与上下文
当前工作台已完成三板块一行并列布局，但通过屏幕截图发现：
1. 预警中心列表文字偏小（12px），标签文字仅10px
2. 端口分析图例文字仅11px，饼状图百分比标签仅10px
3. 图例项内标题与数值间距不明确
4. SVG原生`<title>`悬浮提示无法自定义样式

## 功能需求

- **FR-1**: 预警中心板块内容字体调整为14px
  - 预警标题: 12px → 14px
  - 预警标签(Tag): 10px → 12px
  - 时间戳: 11px → 13px
  - 图标圆圈内字体: 12px → 14px

- **FR-2**: 端口分析板块图例字体调整为14px
  - 图例通道名称: 11px → 14px
  - 图例数值: 11px → 14px
  - 饼状图百分比标签: 10px → 12px

- **FR-3**: 端口分析图例间距调整
  - 图例项内通道名称与数值之间的间距统一为5px
  - 图例项之间的间距保持6px

- **FR-4**: 饼状图自定义悬浮提示
  - 鼠标悬停扇形时显示自定义HTML Tooltip
  - Tooltip字体: 16px
  - Tooltip字重: bold
  - 显示内容: 通道名称 + 数值 + 百分比

## 非功能需求

- **NFR-1**: 自定义Tooltip需流畅显示，无闪烁
- **NFR-2**: 字体调整后布局不溢出、不错位

## 约束

- **技术**: React 18, Ant Design 5, TypeScript, SVG
- **依赖**: AlertCenter.tsx, PortAnalysisChart.tsx

## 假设
- 假设屏幕分辨率为1920x1080及以上
- 假设14px为主要信息展示的合理字号

## 验收标准

### AC-1: 预警中心字体达标
- **Given**: 预警中心已渲染3条以上预警
- **When**: 检查预警标题文字
- **Then**: 字体大小为14px，清晰可读
- **验证**: `human-judgment`

### AC-2: 端口分析图例字体达标
- **Given**: 端口分析图表已渲染
- **When**: 检查左侧图例文字
- **Then**: 字体大小为14px
- **验证**: `human-judgment`

### AC-3: 图例间距为5px
- **Given**: 端口分析图例已渲染
- **When**: 检查通道名称与数值之间的间距
- **Then**: 间距为5px
- **验证**: `programmatic`

### AC-4: 饼状图悬浮提示样式
- **Given**: 端口分析饼状图已渲染
- **When**: 鼠标悬停在某个扇形上
- **Then**: 显示自定义Tooltip，字体16px加粗
- **验证**: `human-judgment`

### AC-5: 饼状图百分比标签可读
- **Given**: 端口分析饼状图已渲染
- **When**: 检查扇形上的百分比标签
- **Then**: 字体大小为12px，清晰可辨
- **验证**: `human-judgment`
