# 修复地区搜索框无反应及控制台错误

## 问题描述

在检测机构管理页面的地图选点组件（`LoftMapPicker`）中，用户在地区搜索框输入地址后点击搜索按钮，地图无任何反应，标记点不出现，地址不更新。同时控制台存在两类错误：

1. **腾讯地图类型错误**：`类型错误：location 应该是 TMAP.LATLNG 类型, 实际却是 OBJECT 类型`
2. **Ant Design 弃用警告**：`bodyStyle` 和 `addonAfter` 属性已被弃用

## 影响范围

- `src/components/LoftMapPicker.tsx`：地图选点核心组件，涉及搜索、标记创建、反向地理编码
- `src/pages/detection/Org.tsx`：检测机构管理页面，使用 LoftMapPicker 组件的表单
- `src/pages/detection/Order.tsx`：检测预约订单页面，包含 Drawer 组件

## 目标用户

- 后台管理员在新增/编辑检测机构时，能正常使用地图搜索和选点功能

## 功能需求

1. **搜索功能正常**：在搜索框输入地址后点击搜索，地图上显示标记点，地址字段自动填充
2. **地图选点正常**：点击地图任意位置能放置标记点并记录坐标
3. **空值校验**：搜索框为空时点击搜索，显示"请输入搜索地址"提示
4. **标记点可见**：标记点在搜索结果位置正确显示

## 非功能需求

1. **无控制台错误**：修复后控制台无类型错误和 Ant Design 弃用警告
2. **TypeScript 编译通过**：`npx tsc --noEmit` 零错误
3. **坐标精度**：搜索结果坐标经 WGS-84 ↔ GCJ-02 正确转换

## 约束

- 不改变地图服务商配置结构
- 不修改 API 服务层
- 保持与现有高德、百度地图的兼容性

## 验收标准

### AC-1: 地址搜索功能
- 类型：rule
- 在地图选点搜索框输入地址（如"陆家嘴"、"北京"），点击搜索后：
  1. 地图上出现标记点
  2. 地址字段被填充
  3. 坐标值正确更新
- 证据：浏览器测试 + 截图

### AC-2: 控制台无错误
- 类型：rule
- 操作过程中控制台无任何 error/warning 级别消息
- 证据：browser_console_messages 输出

### AC-3: Ant Design 弃用警告消除
- 类型：rule
- 页面加载和操作过程中，控制台无 `bodyStyle`、`addonAfter` 相关的弃用警告
- 证据：browser_console_messages 输出

### AC-4: 空搜索校验
- 类型：rule
- 搜索框为空时点击搜索按钮，显示"请输入搜索地址"警告，不发起 API 请求
- 证据：浏览器交互测试

### AC-5: TypeScript 编译
- 类型：rule
- `npx tsc --noEmit` 零错误退出
- 证据：命令行输出

### AC-6: 机构编码重新生成
- 类型：rule
- 点击"重新生成"按钮后机构编码被刷新为新的值
- 证据：浏览器交互测试
